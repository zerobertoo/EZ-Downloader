# Política de segurança

## Versões suportadas

Apenas a versão mais recente publicada em [Releases](https://github.com/zerobertoo/EZ-Downloader/releases/latest) recebe correções de segurança. O app se atualiza sozinho, então basta manter o auto-update ativo.

## Como reportar uma vulnerabilidade

Não abra uma issue pública. Use o [relato privado de vulnerabilidades](https://github.com/zerobertoo/EZ-Downloader/security/advisories/new) do GitHub, informando:

- o que acontece e qual o impacto;
- passos para reproduzir (versão do app e sistema operacional);
- se possível, uma sugestão de correção.

O relato é visível só para quem mantém o projeto. A correção é publicada numa nova versão e o crédito vai para quem reportou, se desejar.
